Glossari de vocabulari tècnic

Backlog
Anglès: Backlog
Definició: És la llista de tasques que tenim pendents de fer.
Exemple: Vam deixar les tasques de proves al Backlog perquè les farem més endavant.

Branca
Anglès: Branch
Definició: És una línia de treball del repositori on podem fer canvis sense tocar una altra branca.
Exemple: Vam crear la branca develop per treballar-hi.

Clon
Anglès: Clone
Definició: És una còpia del repositori que descarreguem al nostre ordinador per poder treballar-hi.
Exemple: Vaig clonar el meu repositori per obrir-lo amb VS Code.

Commit
Anglès: Commit
Definició: És un registre dels canvis que hem guardat a Git.
Exemple: Vaig fer un commit després de crear el fitxer myname.

Estat
Anglès: Status
Definició: Indica en quin punt està una tasca, com ara Backlog o Done.
Exemple: Quan vaig començar una tasca, li vaig posar l'estat In Progress.

Fork
Anglès: Fork
Definició: És una còpia d'un repositori que queda al nostre compte de GitHub.
Exemple: Vaig fer un fork de pallets/flask per tenir la meva còpia.

Git
Anglès: Git
Definició: És una eina que guarda l'historial dels canvis que fem als fitxers.
Exemple: Vaig utilitzar Git per guardar els canvis del projecte.

GitHub
Anglès: GitHub
Definició: És una web on podem guardar repositoris i treballar amb els projectes.
Exemple: Vaig pujar el meu repositori a GitHub.

Incidència
Anglès: Issue
Definició: És una tasca o un problema que creem a GitHub per poder-ne fer seguiment.
Exemple: Vaig crear una Issue per a la tasca del diagrama de classes.

Iteració
Anglès: Iteration
Definició: És un període de treball on posem les tasques que volem fer durant un sprint.
Exemple: Vaig posar les primeres tasques a Iteration 1.

Kanban
Anglès: Kanban
Definició: És una manera visual d'organitzar les tasques en columnes segons el seu estat.
Exemple: Al Kanban podem moure una tasca de Backlog a In Progress.

Merge
Anglès: Merge
Definició: És ajuntar els canvis d'una branca amb una altra.
Exemple: Vam fer un merge per unir els canvis de dues branques.

Origin
Anglès: Origin
Definició: És el nom que normalment fem servir per identificar el repositori remot principal del nostre projecte.
Exemple: Vaig comprovar que origin apuntava al meu repositori de GitHub.

Projecte
Anglès: Project
Definició: A GitHub Projects és l'espai on organitzem les tasques i mirem com avancen.
Exemple: Vaig crear un projecte per organitzar la pràctica de Flaskr.

Pull request
Anglès: Pull request
Definició: És una proposta per revisar uns canvis abans d'ajuntar-los amb una altra branca.
Exemple: Vam obrir una pull request perquè es revisessin els canvis.

Push
Anglès: Push
Definició: És enviar els commits del nostre ordinador al repositori remot.
Exemple: Després del commit, vaig fer push per pujar els canvis a GitHub.

Repositori
Anglès: Repository
Definició: És el lloc on es guarden els fitxers del projecte i l'historial de canvis.
Exemple: El repositori pallets-flask conté els fitxers de la pràctica.

Responsable
Anglès: Assignee
Definició: És la persona que queda assignada per fer una tasca.
Exemple: Em vaig posar com a responsable d'una Issue.

Scrum
Anglès: Scrum
Definició: És una manera de treballar dividint la feina en períodes curts i amb un objectiu.
Exemple: Vam organitzar les tasques de la pràctica en dos sprints.

Sprint
Anglès: Sprint
Definició: És un període de temps en què es treballa en unes tasques concretes.
Exemple: Al Sprint 1 vam posar les tasques inicials del projecte.

Sprint Backlog
Anglès: Sprint Backlog
Definició: És el grup de tasques que hem triat per treballar durant el sprint.
Exemple: Vaig moure les tasques del primer sprint a Sprint Backlog.

Upstream
Anglès: Upstream
Definició: És el nom que fem servir per identificar el repositori original del qual hem fet el fork.
Exemple: Vaig afegir upstream per tenir enllaçat el repositori original de Flask.

Vista
Anglès: View
Definició: És una manera de veure les tasques del projecte, com en un tauler o una taula.
Exemple: Vaig crear una vista Board i una vista Table al projecte.
